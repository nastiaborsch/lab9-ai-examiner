# Лабораторна робота №9
## Тема: Agents — LLM проєкт

### Опис розробленої системи

У межах лабораторної роботи я розробила AI Examiner Agent — LLM-агента для проведення іспиту з обробки природної мови (NLP). Застосунок створений на Python з вебінтерфейсом Gradio. Як мовну модель використано Llama 3.3 70B Versatile через Groq API.

Перед іспитом користувач вводить ім’я та email. Агент перевіряє, чи є студент у списку, після чого випадково обирає дві або три теми. Для кожної теми модель ставить запитання, оцінює відповіді та за потреби ставить додаткове уточнення. Якщо відповідь достатня, студент не знає відповіді або його рівень знань уже можна визначити, агент переходить до наступної теми. Наприкінці він показує загальну оцінку за шкалою від 0 до 10 та короткий відгук про сильні й слабкі сторони.

### Інструменти агента

Для реалізації використано три Python-інструменти. `start_exam(email, name)` перевіряє студента, створює запис про початок іспиту та повертає дві або три випадкові теми. `get_next_topic()` визначає наступну тему. `end_exam(email, score, history)` завершує іспит і записує оцінку та повну історію повідомлень із часовими мітками. Ці інструменти викликаються через механізм LLM function calling. Для перевірки відповідей модель також використовує окремі запити з JSON-результатом, а для збереження інформації застосовано локальні JSON-файли.

### Реалізація та перевірка

Система реалізована у файлах `app.py`, `agent.py` та `exam_tools.py`. У файлі `data/students.json` міститься список студентів, а в `data/exams/` зберігаються результати іспитів. Groq API key вводиться через захищене поле в інтерфейсі та не додається до коду. Для автоматичної перевірки основної логіки підготовлено модульні тести. Роботу реального сервісу необхідно окремо продемонструвати після запуску з власним API-ключем.

### Інструкція із запуску

Потрібно встановити Python 3.10 або новіший, відкрити папку проєкту в PyCharm, виконати `python -m pip install -r requirements.txt`, а потім `python app.py`. Після цього відкрити `http://127.0.0.1:7860`, ввести Groq API key та дані демонстраційного студента (`Тестовий Студент`, `test.student@example.com`).
